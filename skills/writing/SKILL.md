# Writing

Work from the material the author has, whether scattered notes, an outline, or a
finished draft. Explore, arrange, and edit within one flow; enter where the
request starts rather than making the author repeat earlier work.

## What done looks like

The requested text serves its reader and purpose, keeps the author's voice and
supported claims, and makes each idea understandable before relying on it. Deliver
the text or scoped file edit requested, with unresolved factual gaps identified.
An exploration-only request ends with usable raw material, not a forced article.

## How the work goes

- Read the supplied material in full, including any voice sample. Establish the
  reader, purpose, format, and what the reader already knows from available
  context. Ask only about gaps that change the piece. If the message or audience
  needs a consequential decision, use **idea-development** rather than polishing
  around it.
- When material is missing, draw out observations, scenes, claims, and memorable
  phrases from the author. Capture useful fragments without prematurely forcing
  an outline. Keep uncertainty visible. Preserve raw notes separately when making
  a new draft unless the author requested changes to them.
- Arrange the material into beats: each beat makes a move for the reader, such as
  introducing a situation or supporting a claim. Track which concepts the reader
  brings and which the text establishes. Introduce each unfamiliar idea with its
  name before a later beat depends on it; ordinary words can hide missing concepts
  too. Compare openings only when different angles would materially change the
  piece, not as a compulsory selection round.
- Shape the draft paragraph by paragraph around what the reader needs next.
  Recombine fragments rather than preserving their original order. Use prose for
  an argument, lists for parallel items, tables for comparisons, and quotations
  when the wording matters. Cut blocks that add nothing or break the opening's
  promise. End when the purpose is fulfilled, not when every note is consumed.
- Edit for clarity and natural rhythm without flattening deliberate quirks.
  Consult the [tells checklist](references/tells.md) when removing formulaic
  phrasing. For skills or instruction files whose reader is an agent, read
  [agent-facing prose](references/agent-facing.md).
- Re-read file contents before editing to preserve intervening changes. Check the
  result against the original for altered claims, lost qualifications, voice
  drift, and unsupported additions. Return the requested result, not an obligatory
  draft-and-audit transcript.

## Boundaries

Editing changes only the requested text and preserves the author's voice and
facts. Leave code, data, metadata, and link targets intact unless their revision
is requested. Never invent facts or citations; ask for missing evidence or flag
the gap. Clearly fictional invention belongs only in an explicitly creative
request. Writing does not authorize publication or changes to agent permissions.
